# Architecting tool

A model-based systems engineering (MBSE) tool for teams, inspired by [Capella](https://mbse-capella.org) and the Arcadia method, that fits in a modern development workflow:

* **The model is text in git.** Elements are stored in plain, human-readable tables, and diagrams in small text files. Changes can be reviewed, merged and versioned like source code.
* **Every tool is a command.** Checking, querying, rendering and editing all run from the command line, so they fit in continuous integration.
* **Teams can edit together.** A collaboration server shares a model with web browsers, which show and edit it in real time.
* **The modelling method is configurable.** A meta model defines the types of elements, how they may be connected, how diagrams are generated and how the model is checked. A simplified Arcadia meta model is included, and you can define your own.

## Concepts

A model is described at three levels:

| Level | What it contains | Where |
|---|---|---|
| Core model | The fixed building blocks: stereotypes such as `Entity`, `Port`, `Relationship`, `HierarchyRelationship`, `Chain` and `Diagram`. | Built into the tools. |
| Meta model | The types of a modelling method, such as `requirement` or `component`, their attributes, the diagram types, and rules in a small selection language that generate diagrams and check the model. | `metamodel.csv` |
| Concrete model | The elements, with stable identifiers such as `component_2`, and the diagrams. | `model/*.csv`, `diagrams/*` |

Diagrams are either generated by a rule of the meta model, so that they are always up to date, or drawn by listing what they show. Their layout is computed automatically with the [Eclipse Layout Kernel](https://eclipse.dev/elk/), and they are rendered as SVG.

## Getting started

The tools need Python 3.12 or later and [uv](https://docs.astral.sh/uv/); rendering diagrams also needs Node.js, for [elk-cli](https://www.npmjs.com/package/@kieler/elk-cli).

```
uv run archtool check examples/simplified_arcadia          # check the example model
uv run archtool query -r examples/simplified_arcadia "requirement where priority = high"
uv run archtool render -r examples/simplified_arcadia -o out   # render its diagrams as SVG
uv run archtool serve examples/simplified_arcadia          # open http://127.0.0.1:8080/
uv run archtool init examples/simplified_arcadia/metamodel.csv my-model   # start a model of your own
```

| Command | Purpose |
|---|---|
| `archtool init` | Create a model repository for a meta model. |
| `archtool check` | Check a model against its meta model and its verification rules. |
| `archtool query` | Run a query, or evaluate an expression in the selection language. |
| `archtool render` | Render diagrams as SVG files. |
| `archtool edit` | Change a model with commands, from a file or stdin. |
| `archtool serve` | Share a model with web clients, for viewing and editing. |

## Status

The tools are a working first version (MVP), written in Python; they may be ported to Rust once the design has settled, for stable binary distributions. The web client is plain JavaScript, without a build step.

Run the tests with `uv run pytest`, and the type checker with `uv run mypy`.
